Features

Everything Analab Titrator does between the first drop and the final report.

Curve

Live titration curve

Watch pH against volume build up reading by reading while the titration runs.

Endpoint

Automatic endpoint detection

Finds the steepest point of the curve and marks the endpoint for you, so you do not have to read it by eye.

Derivative

Rate-of-change view

See how fast the reading is changing alongside the curve, to confirm where the endpoint sits.

Result

Result calculation

Turns the endpoint volume into a concentration using your sample and titrant details.

Runs

Saved runs

Keep each titration so you can open it again and compare it with another.

Reports

Report generation

Prepare a clear record of the curve, the endpoint and the result for review.
