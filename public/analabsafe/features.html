Features

Compliance and data-integrity tools for your Analab reports and instruments.

Audit

Tamper-evident audit trail

Every login, report view, export and setting change is logged with user, time and workstation, and chained with hashes so any edit can be detected.

Access

Role-based access

Operator, Supervisor, QA, IT Admin and OEM Admin roles, each with its own permissions for viewing, signing, exporting and configuring.

Signatures

Electronic signatures

Review, approve and verify reports with a signature that records who signed, what it means and when.

Records

Verified records

Imported reports are stored as versioned records with a checksum, so you can confirm a file is unchanged.

Alarms

Alarms and warnings

Instrument disconnects, failed imports, failed backups and integrity failures raise alarms that must be acknowledged.

Backup

Backup and restore checks

Run backups and restore drills, and be warned when a scheduled backup is overdue.

Security

Password and session control

Password expiry and history, account lockout after failed attempts, and automatic session lock on timeout.
